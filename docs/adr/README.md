# Architecture Decision Records (ADR)

We record architectural decisions using lightweight Architecture Decision Records.

## File Naming Convention
- Format: `NNNN-title.md` (e.g., `0001-record-architecture-decisions.md`)

## Template & Required Sections
Every ADR must include the following sections:
- **Context**: What is the problem or architectural need being addressed?
- **Decision**: What decision was made and what approach is chosen?
- **Consequences**: What becomes easier or harder as a result? What trade-offs were accepted?
